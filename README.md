# SICAPE — Sistema de Gestão de Apenados

> Sistema web voltado para órgãos, com o objetivo de gerenciar e controlar informações sobre apenados de forma centralizada, segura e eficiente.

**Acesse o sistema:** [www.sicape.software](http://www.sicape.software/)

## Tecnologias

- [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML)
- [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS)
- [JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)
- [Tailwind CSS](https://tailwindcss.com/)
- [Alpine.js](https://alpinejs.dev/)
